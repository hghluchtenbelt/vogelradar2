# Bird observation data sources and APIs for the Netherlands and neighbouring countries

Research date: 2026-10-24. Scope: inputs for a rare-bird occurrence forecast for Vogelradar (recent sightings beyond NL, plus 1 to 2 years or more of history with coordinates).

How to read "verified" in these notes:
- "Verified (API)" means I queried the public GBIF JSON API (api.gbif.org) on 2026-10-24 and report the returned numbers.
- "Verified (page)" means the page was fetched and read.
- "Snippet only" means the page itself could not be opened (403, bot wall, DNS) and the fact comes from the search-engine excerpt of that page. Treat as probable, not confirmed.
- "Prior knowledge, not re-verified" means I could not open any current source for it.

Several key documentation hosts were unreachable from this environment: observation.org and waarneming.nl content pages (BotStopper/Anubis challenge), documentation.ebird.org (DNS failure here, and the host itself serves an Anubis challenge to non-JS clients), science.ebird.org and ebird.org/region (Anubis), birds.cornell.edu (Cloudflare block), gbif.org HTML pages (403; the JSON API worked fine), web.archive.org (not allowed by the fetch tool).

## Key question 1: Observation.org / waarneming.nl / waarnemingen.be (official API, access, terms, sensitive species, history, bulk exports)

### Takeaway
There is an official API, but it is explicitly gated: the docs page at waarneming.nl/api/v1/docs/ and observation.org/api/v1/docs/ now redirects to /api/docs/ and answers HTTP 403 with the text "Access to our internal API is limited to approved applications and use cases", plus a pointer to the FAQ contact form. The only open bulk route is the GBIF dataset "Observation.org, Nature data from around the World" (CC BY-NC 4.0), which blurs Dutch records to a 5 x 5 km grid, excludes Belgium, lags roughly two months, and carries no rarity field.

### Inferences
- Because the GBIF copy is republished roughly weekly (pubDate 2026-10-20) but stops at August 2026, the publication pipeline appears to lag about two months. It is useless for a 48-hour picture, but adequate for a multi-year training set.
- The GBIF 5 x 5 km generalization applies to the whole Netherlands regardless of species, so a forecast trained on it has 0.05 degree spatial resolution for NL; outside NL the same dataset has exact coordinates, so a cross-border model would have mixed precision.
- The "approved applications and use cases" wording means a hobby app will have to make a case through the FAQ contact form. The outcome, any fee, rate limits and endpoint list are not public; I could not confirm whether the API exposes rarity level, embargo status, photos or a "recent rarities" endpoint. From prior knowledge (not re-verified against any live source) the v1 API used OAuth2 with a client id issued by Observation International and exposed observations, species and regions endpoints; treat this as unconfirmed.
- Observation.org's reach for the forecast's neighbouring countries is small compared with the national portals: 0.2 to 0.3 million bird records a year in Germany and France, about 30,000 in Great Britain and 10,000 to 15,000 in Denmark (GBIF counts above), versus 2 million a year in DOFbasen alone (question 3).

### Gaps
- Official endpoint list, authentication flow, rate limits, fee policy and the application form for the Observation International API: the docs require login and the FAQ is behind the bot wall. The user will need to open https://observation.org/pages/faq/ in a browser and use the contact form.
- The platform's embargo and coordinate-blurring rules for sensitive species (as applied on the website and API, as opposed to the GBIF export) could not be read; search only found third-party advice that observers can set "vervaging of embargo" on sensitive breeding birds ([Vogelflits newsletter, waarnemingen.be](https://digital2.amsab.be/digitale_nieuwsbrieven/dn0305_vogelflits/vogelflits_2013/vogelflits_2013_05_18.pdf)).
- Whether the GBIF export contains all observations or only validated ones is not stated in the dataset description.
- The "zeldzaamheden" and "soortenlijst" pages and the user "export"/"my observations" features could not be inspected (bot wall).

## Key question 2: eBird API 2.0, eBird Basic Dataset, and eBird coverage of the Netherlands

### Takeaway
eBird is the only source found with a free, documented, near-real-time API covering all six countries, including a "recent notable observations" endpoint per region or around a point (look-back up to 30 days, radius up to 50 km). Its weakness for the Netherlands is volume: eBird holds roughly 0.6 million Dutch bird records for 2024 against 4.4 million in Observation.org, so Dutch rarities will often be missing or late. Historical data come from the eBird Basic Dataset (monthly, request form, non-commercial terms).

### Cited Findings
- API keys: "Fill out the form at https://ebird.org/api/keygen. The key is generated automatically." (as documented by the ebird-api Python client, version 4.3.1 released 2026-10-12). Verified (page). Source: [PyPI ebird-api](https://pypi.org/project/ebird-api/)
- The same client documents no published numeric rate limit; it handles HTTP 429 with the Retry-After header, doubling its interval up to 60 seconds, and warns: "Use the API with some restraint", excessive downloads could get an account banned, and large projects should contact eBird first. Verified (page). Source: [PyPI ebird-api](https://pypi.org/project/ebird-api/)
- Notable observations parameters and limits (via the rebird R wrapper's reference, which mirrors the API): dist 0 to 50 km (default 25), back 1 to 30 days (default 14), max 1 to 10000, hotspot flag, provisional flag (include unreviewed flagged records), simple vs detailed output. Simple fields: speciesCode, comName, sciName, locId, locName, obsDt, howMany, lat, lng, obsValid, obsReviewed, locationPrivate, subId, exoticCategory. Detailed adds subnational1/2 codes and names, countryCode/Name, userDisplayName, obsID, checklistID, presenceNoted, firstName, lastName. obsDt is "YYYY-MM-DD" or "YYYY-MM-DD hh:mm" when a time was reported. Verified (page). Source: [rebird ebirdnotable](https://docs.ropensci.org/rebird/reference/ebirdnotable.html)
- Historic observations on a date: parameters loc (country, subnational1, subnational2 or hotspot locId), date (ISO 8601), sortKey (mrec or create), categories, max (1 to 10000), fieldSet (simple or full), provisional, limitToHotspots. Full field set adds hasComments and hasRichMedia. The page does not state how far back dates may go. Verified (page). Source: [rebird ebirdhistorical](https://docs.ropensci.org/rebird/reference/ebirdhistorical.html)
- API endpoint paths, from prior knowledge and not re-verified (documentation.ebird.org was unreachable): base https://api.ebird.org/v2/, header x-ebirdapitoken, paths data/obs/{regionCode}/recent/notable, data/obs/geo/recent/notable?lat=&lng=&dist=, data/obs/{regionCode}/historic/{y}/{m}/{d}, ref/hotspot/{regionCode}, ref/region/list/{type}/{parent}. Region codes are ISO country codes (NL, BE, DE, GB, DK, FR) with subnational codes such as NL-NH.
- eBird API Terms of Use: page last edited 19 October 2021; covers ws1.1, ws2.0 and api.ebird.org endpoints; "All data derived from the API are subject to the eBird Data Access Terms of Use"; almost all APIs require a key tied to your eBird account; users are responsible for monitoring their keys' use; the Lab can change the terms without prior notice. Snippet only (page blocked by Cloudflare). Source: [eBird API Terms of Use](https://www.birds.cornell.edu/home/ebird-api-terms-of-use/); mirror [Cornell Confluence](https://confluence.cornell.edu/display/CLOISAPI/eBird+API+Terms+of+Use) (also 403 here)
- eBird Data Access Terms (snippets): data are free for non-commercial use with acknowledgement; "commercial" is defined broadly and includes non-profits generating revenue; derived products may be built but must cite eBird and derived datasets must carry the same terms; original data may not be redistributed in raw form; a new request is needed for a new purpose; reproduction for commercial purposes needs prior written permission; an electronic copy of the product should be submitted to eBird; logos may not be used without permission. Snippet only. Source: [eBird Data Access Terms of Use](https://www.birds.cornell.edu/home/ebird-data-access-terms-of-use)
- eBird Basic Dataset (EBD): "updated monthly (15th of each month), and is available by direct download through eBird to any logged-in user after completion of a data request form. Requests are typically approved within 7 days." Snippet only. Source: [eBird Data Access Terms of Use](https://www.birds.cornell.edu/home/ebird-data-access-terms-of-use)
- EBD format and fields (from the auk R package docs): a tab-separated .txt.gz with 51 columns including latitude, longitude, observer_id, observation_count, time_observations_started, duration_minutes, protocol_name/code, effort distance and area, and the all-species-reported flag; the full file is "over 600 million records" and too large to read unfiltered; filters by species, country, state, bounding box, date, time, duration and protocol are applied after download. The EBD download page is ebird.org/ebird/data/download. Verified (page). Source: [auk documentation](https://cornelllabofornithology.github.io/auk/)
- GBIF sharing and sensitive species (support article modified 28 March 2025): eBird data are "periodically uploaded" to GBIF; for some species output is automatically restricted to reduce risks such as capture or targeted disturbance; downloading sensitive-species data requires an extra verification step; observers can hide their name and hide checklists from Recent Visits and Alerts; eBird Mobile GPS tracks are never shared; checklist coordinates in public outputs are the observer-chosen checklist location (no blurring mentioned). Verified (page). Source: [eBird support: data sharing](https://support.ebird.org/support/solutions/articles/48001078113)
- eBird volume versus Observation.org in the Netherlands (GBIF copies as proxies): eBird EOD Dutch bird records 2022: 390,297; 2023: 521,798; 2024: 598,982; all years 2,964,784. Observation.org Dutch bird records: 2022: 4,494,055; 2023: 4,436,818; 2024: 4,388,163; all years 55,170,152. Verified (API). Source: [GBIF count eBird NL](https://api.gbif.org/v1/occurrence/count?datasetKey=4fa7b334-ce0d-4e88-aaae-2e0c138d049e&country=NL&taxonKey=212); [GBIF count Observation.org NL](https://api.gbif.org/v1/occurrence/count?datasetKey=8a863029-f435-446a-821e-275f4f641165&country=NL&taxonKey=212)
- eBird EOD totals in neighbouring countries (all years): BE 1,245,672; DE 7,209,712; GB 42,437,187 (2024 alone: 7,567,553); DK 1,099,274; FR 6,315,513. Verified (API). Source: [GBIF count eBird GB](https://api.gbif.org/v1/occurrence/count?datasetKey=4fa7b334-ce0d-4e88-aaae-2e0c138d049e&country=GB&taxonKey=212)
- The eBird region page https://ebird.org/region/NL (checklist and observer totals) is served behind an Anubis challenge and could not be read. Verified (page, curl). Source: [eBird region NL](https://ebird.org/region/NL)

### Inferences
- For "rare birds in the last 48 hours" across six countries, calling the notable endpoint once per country code (NL, BE, DE, GB, DK, FR, with back=2 or 3) is cheap: six requests per refresh. Covering a 300 km radius with the geo endpoint would need many 50 km circles, so region codes are the practical route; the response includes lat/lng per record, so distance filtering can be done client-side.
- "Notable" in eBird means flagged by the regional filter (locally rare or out of season), with obsValid/obsReviewed indicating review status; this is a different notion from Observation.org's rarity levels 1 to 4 and will need a mapping (species list) on Vogelradar's side.
- The Dutch eBird volume is roughly one eighth of Observation.org's and grows about 15 to 30 percent a year (counts above), so eBird is best treated as the cross-border supplement, not the Dutch primary.
- The terms allow a free hobby app that stores and derives from API data as long as it is non-commercial and attributes eBird; the "no raw redistribution" clause means Vogelradar should not re-expose eBird records as a bulk download.

### Gaps
- Numeric API rate limits are not documented anywhere I could reach; only the 429/Retry-After behaviour is documented by third-party clients.
- The official API reference (endpoint paths, exact parameter names like detail=full) could not be re-verified; the paths listed above are from prior knowledge.
- The EBD request form, approval criteria and current file size could not be read (science.ebird.org behind Anubis). The GBIF copy of eBird ends at 2024-12-31 (dataset temporal coverage 1800-01-01 to 2024-12-31, pubDate 2025-08-08), so 2025 and 2026 history must come from the EBD or the API, not from GBIF. Verified (API). Source: [GBIF dataset API eBird EOD](https://api.gbif.org/v1/dataset/4fa7b334-ce0d-4e88-aaae-2e0c138d049e)

## Key question 3: GBIF occurrence API and downloads (which datasets, delay, precision, licences, sizes)

### Takeaway
GBIF is the best free route to multi-year history with coordinates, but each dataset has its own blur and delay: Observation.org (CC BY-NC, NL at 5 km, about two months behind), DOFbasen Denmark (CC BY-NC, weekly, exact except blurred breeders, last 7 days withheld), Artportalen Sweden (CC0, current to October 2026), eBird EOD (CC BY, exact coordinates, but ends at 2024), waarnemingen.be (CC0, 5 km, ends at 2018). No GBIF dataset carries a rarity flag, and Germany, France and the UK have no current citizen-science bird feed on GBIF other than Observation.org and eBird.

### Cited Findings
- GBIF occurrence search is paged and refuses offsets above 100,000: a request with offset=100001 returned HTTP 400. Verified (API). Source: [GBIF occurrence search](https://api.gbif.org/v1/occurrence/search?datasetKey=8a863029-f435-446a-821e-275f4f641165&limit=1&offset=100001)
- Asynchronous downloads (DWCA or simple CSV, filtered by predicates such as datasetKey, country, taxonKey, eventDate, geometry) require a free GBIF account; the search endpoint needs no key. Prior knowledge, not re-verified (the techdocs page fetched returned only navigation). Source: [GBIF techdocs occurrence API](https://techdocs.gbif.org/en/openapi/v1/occurrence)
- Observation.org dataset: CC BY-NC 4.0; 66.2 million bird records; NL generalized to 5 x 5 km, other countries exact; Belgium excluded; lag about two months (see question 1). Verified (API). Source: [GBIF dataset API](https://api.gbif.org/v1/dataset/8a863029-f435-446a-821e-275f4f641165)
- DOF/BirdLife Denmark, "Observations from DOFbasen" (key 95db4db8-f762-11e1-a439-00145eb45e9a): CC BY-NC 4.0; 38,348,487 bird records; earliest year 1985; about 2.0 to 2.3 million bird records a year (2022: 2,040,593; 2023: 2,187,108; 2024: 2,095,338; 2025: 2,269,306; 2026 to date: 1,847,140, with October 2026 already at 41,130); pubDate 2026-10-14. Description: "A small number of vulnerable breeding bird observations have their precision blurred by rounding the coordinates and setting the uncertainty to 25 km. The full dataset is updated on a weekly basis, but not including data with an observation date within the last 7 days." A sample 2026 record has coordinates 56.15176, 9.38841 with coordinateUncertaintyInMeters 1790 and the observer's real name in recordedBy. Verified (API). Source: [GBIF dataset API DOFbasen](https://api.gbif.org/v1/dataset/95db4db8-f762-11e1-a439-00145eb45e9a)
- Artportalen (SLU Artdatabanken, key 38b4c89f-584c-41bb-bd8f-cd1def33e92f): CC0; 85,797,838 bird records; Swedish 2026 data present through October (October: 165,895); pubDate 2026-10-17; "Access to ca. 93% of all data contained in the original dataset is unrestricted, the remainder is data for sensitive species as classified by the national checklist of sensitive species managed by SLU Swedish Species Information Centre. This dataset contains the open data." Verified (API). Source: [GBIF dataset API Artportalen](https://api.gbif.org/v1/dataset/38b4c89f-584c-41bb-bd8f-cd1def33e92f)

Verified (API). Source: [GBIF count iNaturalist NL](https://api.gbif.org/v1/occurrence/count?datasetKey=50c9509d-22c7-4a22-a47d-8c48425ef4a7&country=NL&taxonKey=212)

Not usable for point-level rarity history. Verified (API). Source: [GBIF dataset API Faune-France 2020](https://api.gbif.org/v1/dataset/e357cdec-295a-4b91-ac7d-abf5fbbc43bb)

- Sovon on GBIF: "Dutch Centre For Field Ornithology (SOVON) - Breeding Bird Monitoring Program" (key 19c50cd5-d538-43ce-a794-467da1130330), CC BY-NC 4.0, 94,696 bird records (monitoring plots, not casual rarities). The EBCC Atlas of European Breeding Birds (key c779b049-28f3-4daf-bbf4-0a40830819b6, CC BY 4.0, 1,339,711 records) is grid-based atlas data. Verified (API). Verified (API). Source: [GBIF dataset API BirdMap](https://api.gbif.org/v1/dataset/712dba38-74cc-4704-87c0-63d1bf8484bc)

### Inferences
- Download sizes: at the record volumes above, a two-year Dutch extract of Observation.org birds is about 10 million rows and a two-year DOFbasen extract about 4.4 million rows; as GBIF simple CSV this is in the low gigabytes uncompressed (estimate based on the row counts; no file size was measured).
- CC BY-NC datasets (Observation.org, DOFbasen, iNaturalist, BirdMap) are compatible with a free hobby app but not with a paid product or ads; CC0 (Artportalen, waarnemingen.be) and CC BY (eBird EOD) are unrestricted apart from attribution for CC BY.
- Since none of these datasets carries a rarity classification, the forecast needs its own rarity list (for example from Vogelradar's existing rarity-level mapping or the CDNA list) applied to species names.
- For coordinate-level history inside the Netherlands the realistic options are the 5 km GBIF grid, the NDFF Verkenner export (question 4), or the eBird EBD at exact coordinates with low volume; exact Dutch coordinates at full volume exist only inside Observation.org and would need an approved API or data agreement.

### Gaps
- Whether the Observation.org GBIF export is limited to validated records, and the exact republication schedule, are not documented in the dataset metadata.
- The GBIF download file sizes and the download terms page could not be fetched (gbif.org HTML returned 403).

## Key question 4: Euro Bird Portal, NDFF, Sovon, Trektellen, Dutch Birding/CDNA, BirdGuides and Rare Bird Alert, Ornitho, Artportalen/Club300/DOF

### Takeaway
None of these offers a self-service rarity API. NDFF became free open data on 1 January 2025 with a browser-based Flora & Fauna Verkenner (exports up to 100,000 observations, 5 km and 1 km grids, about 1,200 sensitive species blurred, no output API). EBP, Trektellen, Sovon, Ornitho (DDA steering committee form) and BTO all require a written request and may charge; BirdGuides and Rare Bird Alert are paid consumer services without developer access; the CDNA database (dutchavifauna.nl) is browsable under CC BY-NC-ND with no export.

### Inferences
- For Dutch history, the NDFF Verkenner is the only free source that can deliver individual observations beyond the 5 km grid (1 km grid from version 1.2), but it is a browser tool with a 100,000-row export cap and no API, so a multi-year nationwide bird extract would mean many manual exports; the "fair use" clause suggests automation would be frowned upon.
- Trektellen's seawatch and migration counts would be valuable for a forecast (daily species counts at fixed sites), but any use needs written permission from the administrator; the EBP relationship shows the data is shared with institutions, not individuals.
- Ornitho access for a hobby app would go through the DDA steering committee form (and the LPO equivalent for faune-france.org); the questions about commercial background and redistribution suggest a public website counts as redistribution and must be declared.
- The CDNA database could serve as the authoritative rarity list and as a long-run (1888 onward) record of accepted national rarities, but CC BY-NC-ND forbids derived works, so it should be used as a reference, not copied.

- Fees and turnaround for EBP, Sovon, Trektellen and Ornitho requests are not published.

- Club300 and DOFbasen's own website APIs (as opposed to the GBIF copy) could not be documented.

- Movebank is suitable for movement statistics (timing and routes of cranes, geese, storks) rather than for rarity sightings; the EURING_04 reduction profile (0.25 degree rounding) is a convenient low-volume feed for a forecast feature.

### Inferences

- Recommended history stack: GBIF downloads of Observation.org (2 or more years, NL at 5 km, DE/FR/GB/DK exact), DOFbasen (DK exact) and eBird EOD (exact, through 2024), plus an eBird Basic Dataset request to cover 2025 and 2026 for all six countries; use the CDNA list or Vogelradar's rarity levels to label rarities, since no bulk dataset carries a rarity field. - Licence consequence: with Observation.org (CC BY-NC) and DOFbasen (CC BY-NC) in the training data and eBird's non-commercial terms on the live feed, the forecast must remain a non-commercial product with per-source attribution; CC0 Artportalen and CC BY eBird EOD would permit more.

- I found no quantified figure for eBird checklist counts in the Netherlands from eBird itself (region page blocked); the GBIF counts above are the proxy.
